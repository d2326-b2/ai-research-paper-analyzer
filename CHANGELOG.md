# Changelog

All notable changes to HypoGen will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-04-04

### Added
- Initial release of HypoGen
- PDF text extraction and validation
- Research paper summarization using Gemini AI
- Automatic concept extraction from papers
- Knowledge graph generation with relationship mapping
- Research gap identification
- Ranked hypothesis generation (3 levels: Basic, Intermediate, Advanced)
- Structured experiment design proposal
- User authentication with secure password hashing
- Beautiful web interface with knowledge graph visualization
- CORS support for API access
- Comprehensive error handling and fallback mechanisms

### Features
- ✅ PDF upload and processing
- ✅ AI-powered analysis with Google Gemini 2.5
- ✅ User registration and login
- ✅ Secure session management
- ✅ Knowledge graph visualization with Cytoscape.js
- ✅ Export-ready analysis results

### Security
- ✅ bcrypt password hashing
- ✅ Environment-based configuration
- ✅ Session management with Flask-Login
- ✅ CORS protection
- ✅ Input validation
- ✅ Automatic cleanup of temporary files
